-> Subscription Tracker

A simple Python application to help users manage and track their recurring subscriptions (such as Netflix, Spotify, etc.).

->Features
- Add new subscriptions (name, cost, and renewal date)
- View all subscriptions in a list
- Delete subscriptions you no longer need
- Show total monthly cost of all subscriptions
- Data is stored in a `subscriptions.json` file

->Technologies Used
- Python
- JSON (for storing subscription data)
